# 🏦 Bank Indonesia Payment Data Analysis

Proyek ini berisi proses **data cleaning** dan **analisis eksplorasi** terhadap data transaksi Bank Indonesia berdasarkan berbagai kanal pembayaran.

## 📋 Deskripsi

Dataset mencakup transaksi dari beberapa Kantor Perwakilan Bank Indonesia dengan kanal pembayaran seperti **QRIS**, **Kartu Debit**, **Kartu Kredit**, dan **Tunai**. Proyek ini mencakup proses pembersihan data kotor hingga visualisasi hasil analisis.

## 📁 Struktur File

| File | Keterangan |

## 🔧 Tools & Library

- Python 3
- Pandas
- Matplotlib / Seaborn
- Google Colab

## 📊 Tahapan Analisis

1. **Data Cleaning** — menangani missing value, format tanggal, tipe data, dan inkonsistensi nilai
2. **Analisis Kanal Pembayaran** — distribusi transaksi per kanal
3. **Analisis Tren** — tren nilai transaksi per periode
4. **Analisis Korelasi** — hubungan antar variabel numerik
5. **Regresi** — pemodelan sederhana nilai transaksi
